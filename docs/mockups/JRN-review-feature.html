사용자 여정: 기능 하나의 표현이 맞는지 검수하기

이 레이어의 내용은 전부 여정 문서에서 인용한 것입니다. 흐름의 SSOT는 여정 문서이고 이 페이지는 그 흐름을 써볼 수 있게 만든 프로토타입입니다. 두 번째 분기는 이어지는 단계가 다른 여정(코드에서 기능 목록 뽑아내기)의 단계라, 이 여정의 끝으로 표현하고 그 여정의 페이지로 넘깁니다 — 규약은 mockups README 「여정 밖 분기」 절에 있습니다. 여정 문서 §4 의 마지막 행 「12개 중 1~2개만 처리하고 종료 → 여정 재진입」은 이어지는 단계가 없는 정상 종료라 위 목록이 아니라 검수 화면의 「나중에 이어서 볼게요」와 그 갈래의 끝으로 표현했습니다.

## `backend/src/config.rs` — 판단이 갈려 **남긴** 것

- **모듈 머리 주석 5행** — 「`#[derive(Debug)]` 의 **의도된 부재**」는 **코드에 없는 것**이라
  읽어서 복원할 수 없다. `(AC4.3: credentials must not reach logs)` 인용도 여기서는 남겼다 —
  그 부재가 무엇을 지키는지를 가리키는 유일한 표지다.
- **`oauth_redirect_base_url` 의 7행** — GitHub App 콜백 URL 이 와일드카드를 받지 않아 PR 프리뷰가
  각자 등록할 수 없다는 **상류 API 의 제약**. 정책이 이름 붙인 「복원 불가능한 지식」 그 자체다.
- **`sanitize_preview_id` 의 5행** — `~`·`&`·`#` 가 콜백 URL 의 질의 문자열을 위조할 수 있어
  이스케이프가 아니라 **거부**한다는 보안 판단.
- **`worker_token` 의 「Empty means "this deployment has no worker"」 2행** — 빈 값이 fail-open
  이 아니라 fail-closed 라는 불변식.
- **`read_secret` 의 「k8s commonly projects secrets as files」** — 왜 파일 폴백이 있는지.
- **`Mode` 의 stub/real 설명 2행** — stub 이 실제와 갈리는 지점(충실도 경계)은 정책이 유지 대상으로
  명시했다.

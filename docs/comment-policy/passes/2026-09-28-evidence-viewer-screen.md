정책 README 「유지 대상」 첫 항이 **기계가 읽는 주석**을 「정책 대상이 아니며 지문·판정 모두에서

여지도 없다(제자리 재작성 0줄).

### 왜 지문에서 면제하지 않고 판정으로 닫는가

정책의 기계 판독 열거는 **닫힌 목록**이고, 레포 고유 항목은 `검증 시나리오:`·`mock-exception:`
**둘뿐**이다. 목업 매핑 패턴은 거기에 없으므로 지문이 이 줄을 계수하고, 게이트는 판정을 요구한다.
열거를 늘리는 일은 정책 자신이 「앞부분은 도구 공통(**유형 템플릿 고정부**)」이라 적고 사각지대 절이
「유형 템플릿(**control plane**)이 소유한다」고 적은 자리다 ⇒ **data plane 패스가 고칠 수 없다.**
그래서 선례대로 **판정 + 보존**이 유일한 경로이고, 면제를 구하는 것은 이 패스의 범위 밖이다.
